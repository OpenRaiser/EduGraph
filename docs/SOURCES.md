## Textbook catalog sources

Textbook-source metadata and independent catalog views reference [TapXWorld/ChinaTextbook](https://github.com/TapXWorld/ChinaTextbook/tree/e2b3f62213c77bb8c33c5be355f97625ea1b8b61). Source links retain the repository revision and the path identifying each document. EduGraph's structured records describe textbook metadata, catalog positions, and Concept associations.

The rights to textbook PDFs, body text, and artwork belong to their respective publishers and rights holders. These source works are separate from EduGraph's structured-data license.

## Cover previews

The website's [cover notice](../web/assets/covers/NOTICE.txt) and [cover catalog](../web/assets/covers/catalog.json) record attribution and matching information for each preview. Cover artwork remains subject to the original rights holders' terms.

## EduGraph learning resources

Explanation and exercise records carry their authorship, generation, and review provenance. Consult those fields to distinguish generated learning resources from source-derived metadata.
